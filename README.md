# Bubu-Store

** Loja Virtual **

Projeto de uma loja virtual desenvolvido com o objetivo de colocar em prática e aprimorar meus conhecimentos em desenvolvimento web.

Em desenvolvimento!
Este projeto faz parte da minha jornada de aprendizado. A ideia é evoluir a aplicação ao longo do tempo, adicionando novas funcionalidades e aprimorando a experiência do usuário.

🚀 Tecnologias
* HTML5
* CSS3
* JavaScript
* Git
* GitHub

📌 Funcionalidades
* Catálogo de produtos
* Busca de produtos
* Filtros
* Página de detalhes do produto
* Carrinho de compras com localStorage
* Checkout
* Layout responsivo
* Objetivo

Praticar desenvolvimento web, organização de projetos e versionamento de código, aplicando os conhecimentos adquiridos durante meus estudos.

🚧 Status

Em andamento...

Novas funcionalidades e melhorias serão adicionadas conforme o desenvolvimento do projeto.
